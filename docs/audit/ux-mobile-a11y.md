# UX-аудит: «Мобильная версия, клавиатура, ошибки»

Ключ скриншотов: `mobile-a11y` (папка `shots/`). Скрипты: `scripts/mobile-a11y-*.cjs`, сырые логи — `scripts/mobile-a11y-*.out` и `*.log.json`.
Приложение: http://localhost:5199 (Vite dev), ИИ — мок на :8787. Браузер: Chromium из `/opt/pw-browsers/chromium` через playwright-core.
Телефон эмулировался как `viewport 390×844, isMobile, hasTouch, deviceScaleFactor 2`; жесты — через CDP `Input.dispatchTouchEvent` (у Playwright есть только `tap`). Десктоп — 1400×950, без GPU.

## Кратко

1. **Телефон 390 px не помещает интерфейс: страница свёрстана в 532 px и не прокручивается вбок.** Корневая сетка `grid-template-columns: 1fr` (planner.css:969-978) растягивается до min-content шапки (531,7 px, `.pl-header` — flex без переноса). В итоге за правым краем экрана оказываются кнопки «Проверка», «Вид/Слои», «Проект» (новый, открыть, сохранить, экспорт, ссылка) и «Справка», вкладка панели «Проверка» и кнопка сворачивания панели ▾; в свойствах стены не видно полей «Длина» и «Толщина», в электрике — переключателей мощности/плиты/высоты. Нижняя часть интерфейса при этом работает: лента инструментов прокручивается пальцем, вкладки Свойства/Каталог/Электрика достижимы.
2. **Жесты сделаны хорошо**: один палец — панорама, два — пинч и панорама, стена тянется пальцем с живой подписью «сдвиг 70 см» и пересчётом площадей, 3D вращается и масштабируется пальцем, панель сама сворачивается на время расстановки предмета. Один раз из ~7 прогонов пинч «залипал» (сведение не работало после разведения) — воспроизвести под логированием событий не удалось.
3. **Клавиатура на десктопе — сильная сторона**: все шорткаты работают (и в русской раскладке — сравнение по `e.code`), рамка фокуса видна у всех 88 элементов, у иконок есть aria-label. Провалы: модальные окна не перехватывают фокус (Tab уходит за диалог), Esc не закрывает меню «Проект», вкладки панели — не `role=tab`, у тоста нет `aria-live`, предмет из каталога нельзя поставить без мыши. В режиме «Стройка» клик по мебели показывает подсказку «Перетаскивайте объект… R — повернуть», но R/Del/стрелки ничего не делают.
4. **Ошибки файлов обработаны образцово** (txt → понятный тост за 6 мс, пустой/кривой JSON → «Файл не похож на план», план не тронут). **Сбои ИИ — хуже**: мусорный ответ 200 показывает пользователю `Cannot read properties of undefined (reading 'costRub')`, обрыв сети — `Failed to fetch`, зависший запрос нельзя отменить (кнопка «Отмена» заблокирована, Esc не работает, таймаута в клиенте нет).
5. **Производительность на 300 предметах — без претензий**: 60 fps, ни одного провала кадра >50 мс, план грузится за 567 мс, задержка «событие → кадр» на уровне пола измерения (33 мс = два rAF) и не растёт с 20 до 300 предметов.

Ошибок страницы (`pageerror`) — ноль во всех прогонах.

## Что порадовало

- Жесты: панорама одним пальцем, пинч и панорама двумя, перетаскивание стены с живой подписью «сдвиг 70 см» и мгновенным пересчётом площадей и конфликтов (shots 07, 08), орбита и пинч в 3D (25, 26). Панель сама сворачивается на время расстановки предмета (13) — правильный рефлекс для телефона.
- Шорткаты полные и предсказуемые, работают в русской раскладке (сравнение по `e.code`): V W C D N M L, R/Shift+R, стрелки/Shift+стрелки для мебели и стен, Ctrl+D, Del, Ctrl+Z/Y, Esc ступенчато. Тост «Стена идёт вдоль экрана — её двигают стрелки ← →» объясняет, почему стрелка не сработала.
- Видимость фокуса и имена: рамка есть у всех 88 фокусируемых, у 5 иконочных кнопок — aria-label, у полей — подписи, `lang=ru`, landmarks. Диалог ИИ ставит фокус в textarea и закрывается по Esc.
- Ошибки файлов: txt/пустой/кривой JSON — короткие русские тосты за миллисекунды, план не портится; оверлей «Отпустите, чтобы загрузить» объясняет, что произойдёт. Сервер на мусорный запрос отвечает JSON `{"error": …}`, а не HTML.
- «Проверка» при разрыве и при коробке без дверей — точные формулировки с кнопкой действия («Замкнуть разрывы»).
- Производительность: 300 предметов не ощущаются — 60 fps, 0 провалов, задержки не растут.
