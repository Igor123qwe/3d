# UX-аудит: «Мебель, ИИ-расстановка, проверка, 3D»

Проход руками через Playwright (Chromium 1400×950, для 3D — swiftshader; отдельно iPhone-UA 390×844).
Приложение: http://localhost:5199 (Vite dev, ИИ включён и ходит в мок на :8787). Сеть наружу закрыта: polyhaven.com и магазины недоступны — это часть сценария.
Ключ скриншотов: `shots/furnish-*.png`. Скрипты: `scripts/furnish-0[1-6]-*.cjs`, логи шагов — `scripts/furnish-0N.log.json`. Скачанные файлы — `downloads/furnish/`.

## Сводка

Сценарий проходится целиком и без единой ошибки страницы. Сильные места — ghost-превью с направляющими при постановке, «Проверка» с человеческими формулировками и центрированием по клику, полная панель свойств с подсказками дизайнера, 3D в один клик с живым редактированием из панели, честные сообщения при недоступном Poly Haven. Главные трения: после каждой постановки каталог закрывается (3 действия на предмет вместо 2), «Дублировать» кладёт копию сквозь стену в соседнюю комнату, перетащить карточку из каталога на план нельзя (а именно так делают в Planner 5D / Floorplanner), отчёт ИИ без кнопки «Отменить», в 3D не работают Delete и каталог без объяснения. Всё остальное — полировка: пустая выдача поиска без сообщения, техническая ошибка «магазин ответил 403», жёлтые шары-светильники в 3D, отсутствие подтверждения экспорта.

## Что порадовало

1. **Ghost-превью и магниты.** Силуэт под курсором, красная пунктирная направляющая по краю соседа, прилипание к стене (комод 45 → 43), статус-строка с R/Esc — ставить точно с первого клика (furnish-02-ghost-Кресло.png, `PlannerCanvas.tsx:536-541`).
2. **«Проверка» говорит по-человечески.** «Перед „Холодильник“ нужно 90 см свободно — мешает „Стул“», «Дверь при открывании задевает „Кресло“»; клик — план центрируется на объекте, список не пропадает; бейдж пересчитывается мгновенно (24 → 11 после удаления дивана); зоны подкрашивают нарушение прямо на плане (furnish-04-checks-panel.png, furnish-05-issue-clicked.png).
3. **Панель свойств — полная и с подсказками дизайнера.** Размеры, поворот с четырьмя способами (ручка/R/кнопки/поле), высота, 15 цветов, «Отразить» с пояснением «меняет сторону оттоманки», «Зоны эргономики: перед 40 см»; у предметов от ИИ — «✨ спинкой к стене, лицом к телевизору» (furnish-09, furnish-13-ai-item-note.png).
4. **3D в один клик и живое.** 2,7 с до сцены, орбита/сдвиг/зум как везде, «Сверху», «Стены: прозрачные/скрыты», клик по мебели выбирает её и цвет/размер из панели меняют сцену сразу; «Ссылка для телефона» с внятным тостом, USDZ 5,4 МБ за 1,2 с; мебель — не коробки (кровать с подушками, шкаф с ручками) (furnish-01-3d-iso.png, furnish-03-3d-resize.png).
5. **Честность при отсутствии сети.** «Фото 3D» за 0,5 с говорит «нет связи с polyhaven.com» и предлагает обходной путь (GLB по ссылке), ничего не виснет; экспорт PNG/SVG — чистый, самодостаточный, 2080×1680.
6. **Диалог ИИ.** Чипы-подсказки дописываются через запятую, «Где» и «Назначение» с datalist, честное пояснение, что каждый предмет проверяется геометрией; результат — одной правкой, Ctrl+Z откатывает всё (проверено: 12 → 36).

## Ошибки страницы

- `pageerror`: **0** во всех шести прогонах.
- `console.error`: только сетевые — `fonts.googleapis.com` (ERR_CERT_AUTHORITY_INVALID, прокси песочницы; шрифт Inter не грузится, страница на system-ui), `api.polyhaven.com/categories/models` и `/assets?t=models&c=furniture` (ERR_TUNNEL_CONNECTION_FAILED — ожидаемо офлайн), `502` от `/api/product` («магазин ответил 403»), `ERR_ABORTED /api/ai` при перезагрузке (отменённый статус-запрос). Ошибок приложения нет.
