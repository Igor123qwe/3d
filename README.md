# Планировщик квартиры

Браузерный 2D-редактор планировки: стены, двери, окна, мебель с реальными размерами и проверка по правилам эргономики.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/ (деплой на Vercel: vercel.json уже настроен)
```

Точка входа — `src/main.tsx`, страница `/planner.html` дублирует главную для ссылок вида `/planner.html#mode=ar&plan=…`.
Модуль планировщика лежит в `src/planner` и не зависит от остального приложения: его можно встроить в любой React-проект, отрендерив `<PlannerPage onBack={…} />`.

## Модули

| Файл | Назначение |
| --- | --- |
| `types.ts` | Модель данных: стены (`Wall`), проёмы (`Opening`), мебель (`Furniture`), комнаты (`RoomMeta`), размерные линии. Все размеры в сантиметрах. |
| `geometry.ts` | Векторная математика, пересечения, площадь многоугольника, SAT-тест пересечения, внутренний офсет контура. |
| `rooms.ts` | Поиск замкнутых контуров стен (грани планарного графа) → комнаты с площадью по внутренним граням стен. |
| `snapping.ts` | Привязки: точки стен (концы, оси, Т-стыки, орто 0/45/90°, сетка), магнит мебели к стенам, выравнивание объектов друг по другу, посадка проёмов на стену. |
| `catalog.ts` | Каталог мебели и электрики: размеры, зоны эргономики (`clearance`), подсказки дизайнера. |
| `checks.ts` | Проверки планировки: пересечения, свободные зоны, сектор открывания дверей, комнаты без дверей/окон, рабочий треугольник кухни, правила для кроватей, диван–ТВ. |
| `ops.ts` | Чистые операции над планом (добавить/сдвинуть/удалить). |
| `store.ts` | История изменений: undo/redo, режим предпросмотра для перетаскивания. |
| `Glyph.tsx` | Условные обозначения мебели в виде сверху. |
| `Scene.tsx` | Отрисовка плана (SVG): полы, стены, проёмы, мебель, зоны, размеры. Используется и на экране, и для экспорта. |
| `PlannerCanvas.tsx` | Интерактивный холст: инструменты, перетаскивание, поворот, масштаб, пинч, клавиатура. |
| `PlannerPage.tsx` | Страница: панель инструментов, каталог, свойства, проверка, справка, файл/экспорт, автосохранение. |
| `../telegram.ts` | Доступ к Telegram WebApp API (если планировщик открыт внутри Mini App). |
| `templates.ts` | Стартовые планировки (студия, 1-комн., 2-комн.). |
| `exporters.ts` | Сохранение/открытие JSON, экспорт PNG и SVG. |
| `polyhaven.ts` | Фотокаталог: API Poly Haven (модели CC0 с фотореалистичными рендерами), подбор типа планировщика по названию, ссылки на свои GLB. |
| `models.ts` | Загрузка glTF/GLB-моделей (three.js) с кэшем и подменой путей текстур. |
| `scene3d.ts` | Сборка 3D-сцены из плана: стены с проёмами и полотнами дверей, окна, полы, мебель (бокс или модель), поиск входной двери для якоря AR. |
| `View3D.tsx` | 3D-вид (OrbitControls), AR через WebXR (hit-test, якорь по порогу входной двери, подстройка поворота и сдвига), Quick Look для iPhone (USDZ). |
| `share.ts` | Передача плана по ссылке: сжатый JSON в хэше URL (`/planner.html#mode=ar&plan=…`). |

План автоматически сохраняется в `localStorage` (`boop.planner.plan.v1`).

## 3D и AR

- Кнопка «3D / AR» в шапке переключает холст в трёхмерный вид: стены 2,7 м с проёмами, полы, мебель боксами или фотореалистичными моделями.
- **Android (Chrome)**: «AR через камеру» запускает WebXR-сессию. Пользователь встаёт в проёме входной двери лицом внутрь квартиры, наводит кольцо на порог и касается экрана — план закрепляется: середина порога двери совпадает с точкой на полу, направление «внутрь квартиры» — с направлением взгляда. Далее поворот и сдвиг подстраиваются ползунком и стрелками. Стены показываются полупрозрачными, чтобы не спорить с настоящими.
- **iPhone (Safari)**: WebXR недоступен, поэтому «AR на iPhone» экспортирует всю расстановку в USDZ и открывает системный Quick Look; начало координат модели — порог входной двери, модель ставится и поворачивается жестами.
- **Из Telegram Mini App** WebXR не работает во встроенном браузере: «Ссылка для телефона» открывает `/planner.html` во внешнем браузере с планом внутри ссылки.

## Фотокаталог

В каталоге вкладка «Фото 3D» показывает модели Poly Haven (лицензия CC0): категории и превью загружаются с `api.polyhaven.com`, размеры берутся из каталога, тип планировщика (диван, стол, кровать…) подбирается по названию и тегам. Любому предмету можно назначить и свою модель по ссылке на GLB — она используется в 3D и AR.
